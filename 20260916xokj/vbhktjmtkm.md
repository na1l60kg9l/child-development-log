# 蒙脱石散冲上热搜后，药师来和你聊一聊

> 更新时间：2026-09-16 (UTC+8)

2023新年伊始，蒙脱石散突然冲上了热搜榜。事件源于美国疾控中心公布了2022年12月24日至31日新冠感染病例中奥秘克戎新变种XBB.1.5占比超过40%，成为美国头号流行毒株。于是一则关于XBB.1.5主要攻击消化道和心血管系统，需准备蒙脱石散和诺氟沙星等治疗腹泻药物的网络截图在各大平台疯传。

今天药师来和你聊一聊

**01**

**蒙脱石散、诺氟沙星到底是什么药**

蒙脱石散常用来治疗急慢性腹泻，口服后可覆盖保护消化道黏膜，对消化道的病毒、细菌以及产生的毒素有固定、抑制作用，可减少腹泻次数和量，缩短病程。

诺氟沙星是一种抗细菌药物，可用于敏感细菌导致的尿路和肠道感染等。这里需要强调的是，它**只对细菌性腹泻有效，对于病毒性腹泻无效**。

**02**

**XBB新冠病毒感染都需用这些药吗**

既往有报道新冠病毒感染者中约10%会出现腹泻，而XBB毒株目前并无研究证据显示更容易侵犯消化道和心血管系统，一般仍以呼吸道症状为主。未出现腹泻的患者并无使用以上药物的必要。而且腹泻一般为自限性疾病，病程短，所以**建议药物适当准备即可，大量囤药并无必要。**

**03**

**服用这些药物需要注意什么**

**过量用药有风险：**蒙脱石散过量服用可能会导致便秘或胃（肠）结石。

**合用药物有讲究：**由于蒙脱石散的吸附作用，与其他药物同时合用时一般建议需间隔至少1-2小时，减少对其他药物疗效的影响。

**抗菌药物需谨慎：**诺氟沙星对病毒引起的腹泻无效，出现腹泻时需查明病因，不能随意服用。由于该药物对未成年人骨骼生长发育有影响，不宜用于孕妇、哺乳期妇女及18岁以下人群。

**使用诺氟沙星还需要警惕不良反应风险：**

1. 有中枢神经系统疾病、重症肌无力的患者需避免使用。糖尿病患者服用需要加强血糖监测。

2. 可能发生的严重不良反应还包括肌腱炎和肌腱断裂，周围神经病变等。

3. 喹诺酮类药物具有光敏感性，服用期间应当避免过度暴露于阳光下。

**04**

**发生腹泻没有蒙脱石散怎么办**

急性腹泻的治疗，预防和纠正脱水、电解质紊乱是关键，蒙脱石散并非不可缺少的必备药，也不是急性腹泻的一线治疗药物。

**口服补液盐是预防和治疗轻度、中度脱水的首选方法。**大多数患有急性腹泻或胃肠炎的人可以通过摄入水、果汁、运动饮料、汤等来保证液体量和盐的摄入。指南建议儿童急性腹泻时可给予口服补液盐Ⅲ或米汤加盐溶液。

**05**

**哪些情况需要及时就医**

1. 腹泻频繁、量多，伴有中度以上的脱水现象。如口渴、精神差、烦躁不安、皮肤弹性差、指纹皱瘪、脉搏细速、四肢湿冷、血压下降、呼吸深快等。

2. 腹泻伴有明显的全身症状，如高热、严重乏力、食欲不振等。

3. 腹泻伴有严重腹部症状，如恶心、呕吐、腹痛、脓血便、血水样便等。

4. 腹泻伴有其他系统症状，如全身瘀点、瘀斑、皮疹、皮肤巩膜黄染、肾功能不全等。

5. 免疫功能低下人群出现发热、腹泻。如糖尿病、肝硬化腹水、器官移植受者、恶性肿瘤放化疗患者、使用较大剂量激素及免疫抑制剂的患者等。

6. 老年及小儿患者容易出现脱水及器官功能衰竭，建议尽早就诊。
