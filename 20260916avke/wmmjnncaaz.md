# 关爱至伊——人流后优质计划生育服务

> 更新时间：2026-09-16 (UTC+8)

流产后优质计划生育服务 （流产后关爱 ) 简称PAC 。是一项标准化的服务体系，通过向广大的育龄人群宣传避孕知识，同时对刚进行流产手术的女性落实避孕措施，来降低重复流产率。其目的就是告知流产、重复流产的危害，避免高危人流、降低重复人流、减少流产并发症的发生。

　　我院计划生育科在近年的实践摸索中已经初步建立规范化的人流后关爱服务流程。向本科人流术后的女性提供科学避孕知识的宣传和咨询服务，并分别在术后第1、3、6、12个月对所有术后女性进行电话随访，既随访了她们生殖健康的恢复情况，又落实避孕方法的实施，有效的避免了重复流产和高危流产的发生。

　　具有效数据统计，我国每年约有1300万例人工流产，数据分析：中国育龄妇女、尤其是青少年,不仅有较高的流产率,而且重复流产率、高危流产率也处在一个较高水平。人工流产不但会引起月经失调、子宫穿孔、子宫内膜异位症、不孕等并发症,同时也会对受术者产生不同程度的心理压力,未婚者心理障碍程度更严重。

　　计划生育科流产后优质计划生育服务(PAC)的有效开展，将开启保护广大女性的生殖健康及心理健康的新模式。为济宁广大女性朋友的生殖、心理健康保驾护航。
